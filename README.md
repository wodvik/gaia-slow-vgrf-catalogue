# Gaia DR3 Slow-Vgrf Catalogue

This is the first public review-stage release for the probabilistic Gaia DR3
slow-Galactic-rest-frame-speed catalogue.

Zenodo concept DOI: [10.5281/zenodo.20116134](https://doi.org/10.5281/zenodo.20116134)

Release version: `v1.2.0-review` (see `RELEASE_NOTES.md`).

## Key Counts

Tiers are defined on the population-prior-corrected membership probability
(see `RELEASE_NOTES.md`); the uncorrected forward-score counts are given for
reference and are also released.

- Propagated candidate pool: 20,829 stars
- Tier A (`P(Vgrf < 25 km/s) > 0.95`): 173 stars (forward score: 289)
- Tier A+B primary catalogue (`P > 0.84`): 276 stars (forward score: 541)
- Tier A+B+C orbit-summary catalogue (`P > 0.50`): 621 stars (forward score: 1,952)
- Corrected point-estimate `Vgrf < 25 km/s`: 2,755 stars
- Tier purities on the adopted definition: 99.0% / 95.4% / 78.6%

The population-prior tiers are strict nested subsets of the forward-score
tiers: no star enters a tier it was not already in.

## Primary Catalogue Products

Some filenames retain `expanded` as a frozen internal build/provenance label
for the parent-complete public candidate pool. This is not a separate public
release stream and should not be read as a stale legacy sample. Legacy
preselection fields are retained only for provenance audits.

- `catalogues/catalogue_expanded_master.fits`
- `catalogues/catalogue_expanded_tierA.fits`
- `catalogues/catalogue_expanded_tierAB.fits`
- `catalogues/catalogue_expanded_tierABC.fits`
- `catalogues/catalogue_expanded_orbits_tierABC.fits`
- `phase14/expanded_orbit_mc/expanded_catalogue_mc_orbits.fits`
- `phase14/expanded_selection_function.fits`
- `mrt/catalogue_tierA_mrt.txt`
- `mrt/catalogue_tierAB_mrt.txt`
- `mrt/catalogue_tierABC_mrt.txt`
- `mrt/catalogue_orbits_tierABC_mrt.txt`

The MRT products are AAS/CDS byte-by-byte Machine-Readable Tables generated by
`scripts/make_mrt_tables.py` (via astropy), so they are fully regenerable on
every release. The tier tables carry kinematics and chemistry; the orbits table
adds point-estimate orbit summaries and actions. Tier A+B is the primary table.
Sparse chemistry/action fields appear as blank fixed-width columns, flagged with
`?` in each file's byte-by-byte description.

`COLUMNS.md` defines the public FITS/CSV/MRT columns. Gaia `source_id`
values should be treated as integer identifiers and never converted to
floating point.

## Verification

The catalogue source IDs were independently checked against
the ESA Gaia Archive `gaiadr3.gaia_source` table by `source_id`.

- Tier A+B: 541/541 recovered, 0 discrepancies
- Tier A+B+C: 1,952/1,952 recovered, 0 discrepancies

(The archive check was run against the forward-score tiers; the adopted
population-prior tiers are nested subsets of these, so every adopted member is
covered by it.)
- Master catalogue: 20,829/20,829 recovered, 0 discrepancies

The verification report and script are in `online_verification/`.

## Public Smoke Checks

After installing the environment, run the bundle smoke harness from this
directory:

```bash
python tests/smoke_regression.py --bundle-root .
```

The harness checks product presence, source-ID uniqueness, release-schema
columns, and the v1.2.0-review primary counts.

## Reproducibility

`phase14/` contains final review-stage validation and sensitivity
products. The name is a pipeline provenance label; see `phase14/README.md`.

`potentials/` contains the AGAMA `.ini` potential configuration files used by
the shipped orbit scripts. Reviewers still need their own Gaia DR3 mirror only
for a raw parent-buffer rebuild.

`README-submission.md` describes which products can be reproduced from
the release package alone and which require external catalogues or the
large local Gaia parent-buffer scan. `environment.yml` records the
Python environment used for the public products; AGAMA orbit calculations
may require platform-specific installation.
