# Expanded Selection-Function Status

Date: 2026-05-10

The expanded parent-complete catalogue has been evaluated with the Castro-Ginard et al. (2023) Gaia DR3 RVS selection function through `gaiaunlimited.selectionfunctions.DR3RVSSelectionFunction` in a WSL Python environment.  The per-star table is `expanded_selection_function.fits`; summary statistics are in `expanded_selection_function_summary.csv` and `expanded_selection_function_summary.json`.

These inverse-selection weights are retained as contextual observability diagnostics, not as a volume-complete Milky Way deprojection or headline population count.
