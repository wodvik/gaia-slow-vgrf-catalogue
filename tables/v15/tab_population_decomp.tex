\small\textbf{Table \thetable.} Probability-weighted chemodynamic
context.  Spectroscopic abundances are rare in this catalogue, so the
chemical discussion uses the full $\alpha$-classified sample---every
star with both [Fe/H] and an $\alpha$ proxy from APOGEE or GALAH
($n=117$)---rather than only those above the adopted velocity
threshold.  Regions follow \citet{Belokurov2020}, \citet{Helmi2018},
and \citet{BelokurovKravtsov2022}.  $\Sigma P_{\rm pop}$ is the summed
population-prior membership probability, i.e.\ the effective number of
genuinely slow stars each region contributes; $N(P>0.5)$ is the count
surviving the adopted threshold.  The three columns give consistent
proportions, so the mixed chemical character of the sample does not
depend on where the velocity threshold is placed.  Fractions are raw
$N$ shares with Beta$(k+\tfrac{1}{2}, n-k+\tfrac{1}{2})$ Jeffreys
68\% intervals \citep{Cameron2011}; they are wide, which is itself an
argument against extrapolating to the full catalogue.  Per-star
probabilities ship with the catalogue so these regions can be recut.
